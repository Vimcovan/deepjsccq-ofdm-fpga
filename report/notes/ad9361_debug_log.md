# AD9361 纯 PL 配置调试记录（experiment_8）

> 日期：2026-09-25
> 平台：Zynq UltraScale+ xczu5 + AD9361（LVDS，1R1T，FDD），Vivado 2025.2
> 工程：`experiment_8`（原始工程 `原始例程工程` 未改动）
> 业务：类 802.11a OFDM 突发（20 Msps，64 点 FFT，CP 16，16QAM，前导 320 + 数据 1600 = 1920 样点/帧），LO 915 MHz

---

## 1. 结果总览

单板环回（TX1 → 电缆/衰减器 → RX1），分析方法：LTF 信道估计 + 导频公共相位跟踪。

| 阶段 | EVM | 镜像（IQ 失衡） | 主要改动 |
|---|---|---|---|
| 初始状态 | **-22.0 dB**（7.9%） | -25.7 dBc | — |
| 修复 SPI 握手 | -29.7 dB | -36.5 dBc | 问题 2 |
| TX 正交校准相位扫描 | -31.2 dB | -38.7 dBc | 问题 3 |
| TX 数字回退 6 dB | ≈ -31.2 dB | — | 问题 4（削顶消除，上限 -34 → -36 dB） |
| 更换 AD9361 可编程 FIR | -31.3 ~ -32.5 dB | ≈ -37 dBc | 问题 5、6 |
| 相位扫描固化到 PL | **-32.0 ~ -32.2 dB**，每次上电均收敛 | -38 dBc | 问题 7 |

两板空口（10 cm，独立晶振）：用户解调脚本（含采样频偏纠正、导频跟踪）测得 **-32.7 dB**，与单板环回的上限基本一致。

## 2. 问题与解决

### 问题 1：EVM 很大（-22 dB），原因不明

**现象**：单板环回的星座图发散，EVM 约 -22 dB。

**诊断**：离线解调 ILA 抓到的 RX 帧，逐项排除：

| 检查项 | 结果 | 结论 |
|---|---|---|
| LTF 估计的 SNR | 43 dB | 噪声不是瓶颈 |
| 信道幅频 | ±2 dB 平坦 | 滤波正常 |
| FFT 窗口前移 0–12 样点 | EVM 基本不变 | 此时 ISI 不是主因 |
| AM/AM、AM/PM | 平坦 | 无明显压缩 |
| **按镜像子载波建模的 IQ 失衡** | 镜像 -24 ~ -26 dBc，全频带一致，相位稳定 | **主因**：模拟正交误差（不是接口 I/Q 错拍，否则镜像会随频率变化） |

**结论**：正常校准后镜像应在 -45 dBc 以下，说明 **TX 正交校准没有生效**。继续查为什么（问题 2、3）。

排除过的假设：校准时环回线在 RX 口注入信号干扰校准——拔线后上电校准、再接线测，结果不变，排除。

---

### 问题 2：SPI 握手错位一拍，所有"等待校准完成"都被跳过（根因）

**现象**：`ad9361_config` 的 LUT 里有 `0x016` 轮询（等 BBDC/RFDC/滤波器调谐/TX quad cal 完成），但校准效果很差，而且每次上电残余都不一样。

**根因**：`ad9361_spi.v` 在 state0 **不等请求**就锁存命令、循环发帧：

```
state0 → 锁存当前 address/data（不管有没有新请求）→ state1 发 24 bit → state2 拉低 waitrequest 一拍 → state0 ...
```

`ad9361_config` 看到 `waitrequest` 变低就认为"当前命令已完成"，但那一拍其实对应的是 **SPI 把上一条命令又发了一遍**。结果：
- 每条命令都被发两次，应答整体错位一个事务；
- 写之后紧跟的轮询读，读到的是**写帧期间的 MISO**，不是寄存器内容；
- "等 `0x016[x]==0`"的判断因此**立即通过**，后续的 RX 跟踪使能、ENSM 配置、**TX 衰减写入**都在 TX 正交校准还没跑完时就发生了。

**解决**：
- `ad9361_spi.v`：新增 `I_start`，state0 只在收到请求时才锁存并发帧；
- `ad9361_config.v`：state1 产生一拍 `O_start`。

**效果**：EVM -22.0 → **-29.7 dB**，镜像 -25.7 → -36.5 dBc。

---

### 问题 3：TX 正交校准不收敛（Eval Software 脚本用了固定的 NCO 相位）

**现象**：读 `0x0A7`（TX1 quad cal 状态）= `0xFC`，bit1（LO 收敛）和 bit0（SSB 收敛）都是 0。

**根因**：ADI Linux / no-OS 驱动的 `ad9361_tx_quad_phase_search()` 会**扫描 RX NCO 相位偏移 0–31**，取收敛窗口的中点（openwifi 里 `last_tx_quad_cal_phase` 就是这个结果）。而 AD9361 Evaluation Software 生成的脚本只用**固定相位**（`0x0A0 = 0x5F`，即 phase 31），在 915 MHz 下正好落在收敛窗口外面。

**解决**：
1. 先在板上通过 VIO 做扫描：原 FIR 下收敛窗口是 phase 1–3，选 2。镜像 -38.7 dBc，EVM **-31.2 dB**。
2. 后来发现**收敛窗口会随 FIR 群时延变化**（换 FIR 后变成 1–7），固定值不够稳，于是把扫描固化到 PL（问题 7）。

---

### 问题 4：TX 数字峰值被削顶

**现象**：固定帧里第 8 个数据符号的 EVM 总是比其他符号差约 10 dB；最高 1% 幅度的样点增益下降、误差增大。

**根因**：`truncation_and_saturation` 取 IFFT 输出的 `[18:3]`，数据的每路 rms 约 643，只比 12 bit 满量程低 10 dB。OFDM 的峰均比有 10–12 dB，第 8 个符号的理想峰值是 **2565，超出 ±2047 满量程 25%**，被饱和削顶。

**解决**：
- `truncation_and_saturation.sv`：改为取 `[18:4]`（-6 dB，rms 约 322，峰值 ≤ 约 1300）；
- `preamble_insert.sv`：前导码同样算术右移 1 位，保持和数据的相对电平一致（没有改 `原始例程工程` 下的 mem 文件）；
- LUT：TX 衰减 `0x073/0x075` 由 10 dB 改为 **4 dB**，把损失的功率补回来。

**效果**：去掉 IQ 失衡后的 EVM 上限由 -34 dB 提高到 -36 dB，AM/AM 在最大幅度处也恢复平坦。

---

### 问题 5：AD9361 可编程 FIR 太陡，振铃超出 CP，产生 ISI

**现象**：每次抓取的逐符号 EVM 图案几乎完全一样，说明是**由数据决定的确定性误差**；但 AM/AM 平坦，不是无记忆的非线性。

**诊断**：
- 用"前导码 + 判决重构的数据"对整帧做 60 阶最小二乘拟合，得到端到端冲激响应：主径前后有缓慢衰减的拖尾（前拖尾到 -20 样点，后拖尾到 +15），**CP 以外的能量约 -29 dB**，正好对上当时的误差底；
- FFT 窗口往 CP 里提前 8 个样点，EVM 提升 1.3 dB，也证实存在 ISI；
- 从 LUT 里提取 FIR 系数：TX 和 RX 都是 Eval Software 自带的 `10MHz.ftr`，**128 阶"砖墙"**，通带到 9.9 MHz，11 MHz 处就到 -66 dB，过渡带只有约 1 MHz。单个滤波器在 ±8 个样点以外还有 -24.7 dB 的能量。

**解决**：用 Kaiser 窗重新设计（`tools\lut_replace_fir.py` 自动替换 LUT 里的两段 FIR 编程并重新编号）：

| | 原始 | 新 RX | 新 TX |
|---|---|---|---|
| 抽头数 | 128 | **48** | **64** |
| 截止 / 阻带 | 9.9 MHz / 1 MHz 过渡带 | 10.0 MHz / 70 dB | 10.3 MHz / 70 dB |
| 8.3 MHz 处 | 0 dB | 0 dB | 0 dB |
| 11.7 MHz（第一镜像边缘）处 | -68 dB | -53 dB | -36 dB（13 MHz 以上 < -77 dB） |
| ±8 样点以外的能量 | -24.7 dB | -44.8 dB | -35.1 dB |

系数的 DC 和与原滤波器保持一致（TX 65508，RX 32754），增益不变；`0x065/0x0F5` 的抽头数字段相应改为 `0x7A/0x5A`。

**效果**：只换 RX FIR，EVM 就从约 -31.4 提升到 -32.9 dB。

---

### 问题 6：TX FIR 用 48 阶时，发出去的是乱码

**现象**：TX 和 RX 都换成 48 阶后，RX 上完全没有 OFDM 结构（STF 自相关只有约 0.3），AGC 把增益拉到最大（`0x2B0 = 0x4C`）。曾一度怀疑是线缆问题，用户检查后确认连接正常。

**定位**（通过 VIO 在运行时重新加载 FIR，不用重新编译）：

| TX FIR | RX FIR | 结果 |
|---|---|---|
| 新 48 阶 | 旧 128 阶 | ❌ |
| 旧 128 阶 | 旧 128 阶 | ✅ |
| 旧 128 阶 | 新 48 阶 | ✅（EVM -32.9 dB） |
| Kaiser 64 阶 | 新 48 阶 | ✅ |
| Kaiser 128 阶 | 新 48 阶 | ✅ |

**结论**：在 2 倍插值下，**TX FIR 的抽头数要取 32 的倍数**（48 阶不行）；RX FIR 用 48 阶没问题。生成脚本里已经加了这条检查。

**连带发现**：换 FIR 会改变群时延，TX 正交校准的收敛窗口也随之移动（原来是 1–3，换后是 1–7）。所以**每次改 FIR 或改频点，都必须重新做相位扫描**。

---

### 问题 7：相位扫描依赖手动操作 → 固化进 PL

**需求**：上电自动完成全部配置，不需要任何 VIO 操作。

**解决**：新增 `ad9361_txq_search.v`，LUT 配置完成后自动运行，流程与 ADI 驱动一致：
1. 保存 `0x014/0x169` → 强制 ENSM 进入 ALERT（`0x014 = 0x0D`，等 `0x017[3:0] == 5`）→ 关闭 RX 正交跟踪；
2. 对 phase 0–31：写 `0x0A0 = {RX_NCO_FREQ, phase}`，写 `0x0A1`（先带软复位写一次，再不带软复位写一次），写 `0x016 = 0x10`，等 `0x016[4]` 清零，读 `0x0A7[1:0]`；
3. 取最长连续收敛段（首尾相接也算）的中点；一个都不收敛时用默认值 phase 4；
4. 在选中的相位上做最终校准，恢复 `0x169/0x014`，等 ENSM 回到 FDD（`0xA`）；
5. 所有状态轮询都有超时保护，出错时置 `O_err`。

SPI 按"LUT 配置 → 相位扫描 → VIO 调试"的顺序交接；**LED 改为扫描完成后才点亮**（`rf_ready`）。结果通过 VIO 可以读出，也可以通过 VIO 触发重跑（换频点时使用，重跑期间会中断几毫秒的收发）。

**验证**：
- xsim 行为仿真：普通窗口、首尾相接的窗口、全部收敛等情况全部通过；
- 板上 3 次上电：收敛窗口 2–7 / 1–7 / 2–6 → 选中 5 / 4 / 4，最终 `0x0A7[1:0] = 11` 每次都收敛；EVM -32.0 ~ -32.2 dB。

---

### 问题 8：两板空口对收时，接收板的 AGC 在帧中间跳变

**现象**：接收板用的是同一个 bitstream，它自己也在发。有一帧在第 3 个符号处增益**突降 0.6 dB**，只纠公共相位时 EVM 降到 -19 dB。

**诊断**：
- 接收板自己的 TX 泄漏进它的 RX；两块板的突发不同步，所以功率时变，快速 AGC 就会被触发；
- 另外还有 0.8~1.6 dB 的**缓变**增益，接收端改成手动增益后仍然存在，所以不是 AGC 引起的；可能来自 10 cm 空口的近场/多径，或者片内 TX 在突发开始后的建立过程；
- 两块板各用独立晶振，帧与帧之间频偏在 -86 ~ -1355 Hz 跳动，帧内还有残余频偏；采样钟偏差可以忽略。

**处理**：
- 缓变的增益和相位由接收机用导频跟踪即可（用户脚本实测 -32.7 dB，已经证明可行），不再深究；
- **需要避免的是增益突变**：接收期间接收板不要发射（用 ENSM 引脚做 TDD 控制，或者把 TX 衰减拉满），或者在前导码之后锁住 AGC，帧结束再释放（`0x110` 配置 / `EN_AGC` 引脚；帧长固定，PL 能准确知道释放时机）。

## 6. 经验总结

1. **先确认配置"真的执行了"，再去调参数。** 这次最大的问题是 SPI 握手错位导致校准等待被跳过，所有表面现象（镜像大、每次上电结果不同）都源于此。给配置状态机加一个运行时回读寄存器的通道（VIO SPI），是性价比最高的调试投入。
2. **Eval Software 生成的脚本不能直接照搬。** 它的 TX 正交校准用固定相位，FIR 是按通用场景设计的陡峭滤波器；ADI 驱动里的相位扫描、按业务带宽设计 FIR，这些在纯 PL 方案里都要自己补上。
3. **OFDM 要同时考虑 PAPR 和 CP。** 数字回退至少要留 12 dB；芯片内滤波器的冲激响应必须落在 CP 以内。
4. **校准结果和 FIR、频点是耦合的。** 改了其中任何一个，都要重新做相位扫描，所以扫描应该放在 PL 里自动完成。
5. **分清"缓变"和"突变"。** 缓变的增益和相位交给导频跟踪；AGC 的突变要从系统上避免（接收时不发射、帧内锁定增益）。

## 7. 遗留事项

- 做 `BOOT.BIN`（FSBL + PMUFW + bitstream）实现脱离 JTAG 上电（用户自行完成）
- TDD 引脚控制（ENSM），以及帧内锁定 AGC
- 如果要支持更高阶调制（如 256QAM），可以继续压 TX 正交校准残余（目前约 -37 ~ -38 dBc），以及另一项约 -37 dB、与信号幅度无关的误差底（可能来自残余 ISI 或相位噪声，尚未拆分）
