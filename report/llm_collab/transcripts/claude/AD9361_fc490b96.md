## 小结：openwifi 对 AD9361 做了什么

1. **改 ADI 驱动**：导出 4 个内部函数，新增 1 个 AGC 属性，放宽 LVDS 校准。
2. **绕过 IIO 直接操作**：openwifi 模块拿到 `ad9361_rf_phy` 指针，直接调内部函数，用来换 LO、手动校准、选天线、开关射频。
3. **FPGA 抢 SPI**：收发切换时由硬件直接写 0x051 开关 TX LO，速度比软件快得多。
4. **CTRL_OUT 读增益**：FPGA 实时读 AGC 增益来算 RSSI。

## 一、整体架构（全部在 PL）

```
            ┌────────────────── PL ──────────────────────┐
 RESETB ◄───┤ ad9361_cfg                                  │
 SPI    ◄──►│  ROM(寄存器脚本) → 解析引擎 → SPI 主机     │── cfg_done
            │                                             │
 ENABLE ◄───┤ ensm_ctrl (TX/RX 引脚控制)                 │◄─ tx_burst_req

            │                                             │
 LVDS RX ──►│ ad9361_if: IBUFDS/IDDR/IDELAY → 12bit I/Q ─►│─► OFDM RX (20 Msps)
 LVDS TX ◄──│           ODDR/OBUFDS  ◄─ 12bit I/Q ◄──────│◄─ OFDM TX (20 Msps)
            └─────────────────────────────────────────────┘
```

模块分工：
1. **ad9361_cfg**：上电后自动执行寄存器脚本，完成之后拉高 `cfg_done`。
2. **ad9361_if**：自己写 LVDS 接口，**不用 ADI 的 axi_ad9361 IP**。那个 IP 复位后 ADC/DAC 核一直处于复位状态，DAC 数据源默认也是 DDS，都要软件通过 AXI-Lite 去配，和"尽量不用 PS"的目标冲突。
3. **ensm_ctrl**：用 ENABLE/TXNRX 引脚控制 AD9361 的收发状态机（ENSM），运行时不需要再碰 SPI。
4. OFDM 基带直接跑 20 Msps。

## 三、纯 PL 配置方法（米联客路线）

### 1. 生成寄存器脚本
用 ADI 的 **AD9361 Evaluation Software**（Windows，离线就能用），按上表填好参考时钟、1R1T、LVDS/CMOS、20 Msps、带宽、LO 频率、FIR、增益模式，然后在 Advanced 页导出 **Init Script**。导出的是这样的文本：
```
SPIWrite 3DF,01
SPIRead  37
WAIT     1
WAIT_CALDONE BBPLL,2000
WAIT_CALDONE RXCP,100
...
```

### 2. 用脚本转成 ROM（.coe/.mem）
建议每条指令 32 bit：`[31:28] 操作码 | [27:18] 地址 | [17:10] 数据 | [9:0] 参数`
- `WR`：写寄存器
- `DLY`：等 N µs
- `POLL`：读寄存器，按掩码比较，直到满足条件或超时

`WAIT_CALDONE` 对应的轮询条件（这是米联客等教程的通用做法，请对照 UG-570 核实）：

| 脚本标签 | 轮询寄存器 | 完成条件 |
|---|---|---|
| BBPLL | 0x05E | bit7 = 1 |
| RXCP | 0x244 | bit7 = 1 |
| TXCP | 0x284 | bit7 = 1 |
| RXFILTER | 0x016 | bit7 = 0 |
| TXFILTER | 0x016 | bit6 = 0 |
| BBDC | 0x016 | bit0 = 0 |
| RFDC | 0x016 | bit1 = 0 |
| TXQUAD | 0x016 | bit4 = 0 |

### 3. SPI 主机
- 模式：CPOL=0、CPHA=1（对应 openwifi 设备树的 `spi-cpha`），4 线，MSB 在前
- 帧长 24 bit：`[23]=W/R̄`、`[22:20]=字节数-1`、`[17:8]=地址`、`[7:0]=数据`
- 时钟：≤10 MHz（openwifi 用 `spi-max-frequency=10MHz`）
- 注意：openwifi 的 [spi.v](../../openwifi-hw/ip/xpu/src/spi.v) 是 LSB 先出，所以它的常量是按位反转过的，别照抄那个位序

### 4. 上电流程
PL 把 RESETB 拉低 ≥1 µs，然后释放，等几 ms，开始执行 ROM。**第一条先读 0x037**，确认芯片 ID，这样能最早发现 SPI 本身的问题。

### 5. 补上 openwifi 的 AGC 改动
openwifi 通过补丁新增的 `fagc-dig-sat-ovrg-enable`，本质上就是把 **0x101 的 bit7 置 1**。纯 PL 下在脚本末尾多写一条就行，不用改任何驱动。

1. **Fast AGC 参数**：[openwifi_32_ad9361.dtso](../kernel_boot/boards/openwifi_32_ad9361.dtso) 里 `adi,fagc-*`、`adi,agc-*`、`adi,gc-*` 这一整组，是针对 802.11 前导码调过的，比如 `fagc-state-wait-time-ns=260`、`fagc-lock-level=10`。在 Eval Software 的 AGC 页面逐项填进去，导出的脚本里就包含了。
2. **优化后的 AGC 寄存器**：[agc_settings.sh](agc_settings.sh) 的 "optimized" 分支（0x15C/0x106/0x103/0x101/0x110/0x114/0x115/0x10A）可以作为第二套方案，接在脚本末尾，和默认值对比效果。注释里特别提到 0x110 不要写成 0x4A。
3. **TX 正交校准**：openwifi 每次改 LO 都要手动做 TX_QUAD_CAL（`sdr.c:225`）。你的频点固定，脚本里的 `WAIT_CALDONE TXQUAD` 执行一次就够了，但**如果以后要改频点，要重新跑这段校准**。
4. **LVDS 接口时序**：[ad9361_conv.patch](../kernel_boot/ad9361_conv.patch) 说明连 ADI 的自动接口调谐在高速率下都不稳定。你只跑 20 Msps，时序余量很大，用**固定的延时值**就可以。
5. **DC 问题**：零中频下 TX LO 泄漏和 RX 直流都落在 0 号子载波上，而 802.11a 的 DC 子载波本来就是空的。只要在脚本里保留 RX 的 BB DC 和 RF DC 跟踪以及正交跟踪（Eval Software 默认是开的），就不需要做 openwifi 那样的偏频。

## 五、收发控制（ENSM）

**推荐：TDD + 引脚控制（level 模式）**
- 在脚本里打开 ENSM 引脚控制（0x013/0x014，具体位按 UG-570 设置）
- PL 用 `TXNRX` 选择收或发，`ENABLE` 拉高进入对应状态
- 发射板只在突发期间进 TX，其余时间停在 ALERT。这样 TX LO 不会一直泄漏，起到了 openwifi `spi.v` 开关 0x051 的作用，而且不用碰 SPI
- 接收板一直处于 RX
- TX 从 ALERT 切到 TX 需要一段建立时间（几十 µs 量级），**burst 请求要提前拉高**，或者在帧前补一段零
- 固定帧长的情况下，PL 可以准确算出什么时候关 TX

**备选：FDD 常开（和 openwifi 一样）**
最省事，但发射板在空闲时也会一直有 LO 泄漏。实验室调试可以先用这个。

## 六、LVDS 接口要点（1R1T，20 Msps）

- `DATA_CLK = 40 MHz`（1R1T LVDS 下是 2×fs），DDR 模式，每个 12 bit 样点分成高 6 位和低 6 位两拍传，由 `RX_FRAME` 标记对齐
- RX 路径：IBUFDS → IDELAYE2（固定抽头）→ IDDR；用 DATA_CLK 经 BUFG 得到的 `l_clk` 作为接口时钟，再用 FIFO 或双口 RAM 跨到基带时钟域
- TX 路径：ODDR 输出数据、`TX_FRAME`，以及 `FB_CLK`（把 DATA_CLK 转发回去）
- **接口调通的方法**：利用 AD9361 自己的 BIST
  - 0x3F4：让 RX 输出 PRBS 或单音，用来扫 IDELAY 或 0x006，找到窗口中心
  - 0x3F5 bit0：数字环回，TX 数据直接绕回 RX，用来校验 TX 接口和 0x007
  - 找到值之后固化进脚本或 IDELAY 参数
