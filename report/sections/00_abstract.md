# 基于FPGA的DeepJSCC-Q实时无线图像传输系统

## 摘要

传统的无线图像传输采用分离信源信道编码（SSCC）：先用JPEG等压缩，再加纠错码和调制。信道SNR低于纠错码门限时，整幅图像无法解码，出现“悬崖效应”。深度联合信源信道编码（DeepJSCC）用一对神经网络把图像直接映射为信道符号，画质随SNR平缓变化；DeepJSCC-Q进一步把符号约束到QAM星座上，能够接入标准的数字物理层。但它的计算量大，接收端又必须使用未经判决的软符号，对硬件资源和物理层同步精度都提出了很高要求。

本作品用两块PYNQ-ZU（Zynq UltraScale+ xczu5eg）和两块AD9361射频子卡，实现了一条915 MHz的实时无线图像链路。DeepJSCC-Q编码器、解码器与类802.11a OFDM物理层全部在PL中实现：神经网络在保持信道符号数不变的前提下缩小通道数与下采样倍数，乘加量降为原网络的约1/51，以W8A12整数运算、106个逐层流水的卷积引擎在250 MHz下运行，权重与激活全部存放在片上；物理层面向683个OFDM符号的长帧设计了二阶SFO跟踪与PN符号翻转，均衡后的连续I/Q直接送入解码器；PS负责取图、射频控制与触摸屏显示，并调用Mali-400 GPU渲染信道三维图。

实测表明：系统以30 fps连续传输256×256彩色图像，PL内端到端时延71.5 ms；在每幅图同样32,768个64QAM符号、同一物理层的条件下，DeepJSCC-Q在高SNR时PSNR比JPEG + 卷积码基线高3.8 dB，并在SNR从32 dB降到5.5 dB的过程中平缓退化，而基线在约17–20 dB处断崖式失效。与已发表的FPGA DeepJSCC实现相比，本作品的卷积工作量是其10.5倍，编码器DSP用量仅为其15 %。

关键词：深度联合信源信道编码；FPGA；OFDM；软件无线电；实时图像传输
